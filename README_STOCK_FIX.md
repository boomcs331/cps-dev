# แก้ไขปัญหาการโหลดข้อมูลในหน้าสต็อกวัตถุดิบ

## ปัญหาที่พบ
- เกิดข้อผิดพลาดในการโหลดข้อมูลในหน้า `materials/stock`
- ตัวแปร `$materials`, `$locations`, และ `$stockLots` ไม่ได้ถูกส่งจาก Controller

## การแก้ไข

### 1. แก้ไข MaterialController.php
- เพิ่ม error handling ในเมธอด `stock()`
- ตรวจสอบให้แน่ใจว่าข้อมูลทั้งหมดถูกส่งไปยัง view
- เพิ่มการจัดการข้อผิดพลาดและแสดงข้อความที่เหมาะสม

### 2. แก้ไข stock.php
- เพิ่มการตรวจสอบตัวแปรก่อนใช้งาน
- เพิ่ม error handling สำหรับกรณีที่ไม่มีข้อมูล
- แก้ไข JavaScript ที่ไม่สมบูรณ์
- เพิ่มฟังก์ชันสำหรับแสดงรายละเอียดสต็อกแต่ละวัตถุดิบ

### 3. สร้างไฟล์ช่วยเหลือ
- `test_db.php` - ทดสอบการเชื่อมต่อฐานข้อมูล
- `debug_stock.php` - ตรวจสอบข้อมูลจาก Material Model
- `setup_database.php` - ตั้งค่าฐานข้อมูลอัตโนมัติ
- `create_tables.sql` - สคริปต์สร้างตารางและข้อมูลตัวอย่าง

## วิธีใช้งาน

### ขั้นตอนที่ 1: ตรวจสอบการเชื่อมต่อฐานข้อมูล
```
http://localhost/cps-dev/test_db.php
```

### ขั้นตอนที่ 2: ตั้งค่าฐานข้อมูล (หากจำเป็น)
```
http://localhost/cps-dev/setup_database.php
```

### ขั้นตอนที่ 3: ตรวจสอบข้อมูล
```
http://localhost/cps-dev/debug_stock.php
```

### ขั้นตอนที่ 4: เข้าใช้งานหน้าสต็อก
```
http://localhost/cps-dev/?url=materials/stock
```

## ฟีเจอร์ที่เพิ่มเติม

### 1. การกรองข้อมูล
- กรองตามวัตถุดิบ
- กรองตามสถานะ (พร้อมใช้งาน, จองแล้ว, ใช้แล้ว)
- กรองตามคลัง

### 2. การแสดงผล
- ตารางสรุปวัตถุดิบทั้งหมด
- รายละเอียดสต็อกแต่ละกล่อง/ล็อต
- QR Code สำหรับแต่ละกล่อง

### 3. Error Handling
- แสดงข้อความเมื่อไม่มีข้อมูล
- จัดการข้อผิดพลาดจากฐานข้อมูล
- ป้องกันการแสดงผลเมื่อตัวแปรไม่ได้ถูกกำหนด

## หมายเหตุ
- ตรวจสอบให้แน่ใจว่า XAMPP ทำงานอยู่
- ตรวจสอบการตั้งค่าฐานข้อมูลใน `config/config.php`
- หากยังมีปัญหา ให้ตรวจสอบ error log ของ Apache/PHP
